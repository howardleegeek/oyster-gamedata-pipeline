# Real depth/ pipeline — DepthAnything V2 inference, replace empty placeholder

## Goal
Replace the empty `depth/` directory placeholder in
`bin/recorder_consumer_lite.py` (currently raises `RuntimeError` in commit
`ca634ce` because we refuse to ship empty `depth/`) with a real
DepthAnything V2 inference pipeline.

After the recorder produces `clip-*/video.mp4`, run depth inference and
populate `clip-*/depth/` with per-frame EXR files matching the buyer
spec.

Output: `bin/recorder_depth_pipeline_real.py` providing:

```python
def generate_depth_directory(video_path: Path, depth_dir: Path,
                             *, fps: int = 30) -> dict:
    """Run DepthAnything V2 on every frame of video_path.

    Args:
        video_path: input mp4 (CFR 30fps).
        depth_dir: output directory (will be created); per-frame EXR
                   written as 0000.exr, 0001.exr, ...
        fps: must match recording fps (PRD: 30).

    Returns:
        manifest dict {frame_index: sha256_of_exr_file_bytes}.

    Raises:
        FileNotFoundError: if model weights or video missing.
        RuntimeError: if any frame's depth inference fails — NEVER write
                      a partial directory.
    """
```

## Hard requirements

1. Use **DepthAnything V2 ViT-S** (~25M params, CPU-friendly).
2. Frame extraction: use **`imageio` + `imageio-ffmpeg`** (NOT cv2 — cv2
   is not available on minipc-bwdxs WSL pytest environment).
3. EXR write: use **`OpenEXR` + `Imath`** (already in `pyproject.toml`
   `[project.optional-dependencies] exr`).
4. EXR format: 1920×1080 single-channel float32 (matches PRD spec p4).
5. NO 16×16 all-zeros placeholder. NO hardlinking. Every frame is a
   real inference output.
6. If any frame fails (OOM / weight load fail / video corrupt), **abort
   the whole clip** — do not ship partial depth. Use a `try/finally`
   that rmtree's the depth_dir on failure.
7. Model weights ship via PyInstaller `--add-data`. NO download-on-first-run.

## Constraints

- Pure Python via `imageio` + `imageio-ffmpeg` + `OpenEXR` + `torch`.
- **NO `cv2`** — minipc-bwdxs WSL pytest does not have it installed.
- Must work on Windows + Linux (CPU-only path is fine for V1).
- Memory budget: 2 GB RAM for inference.
- Test environment: minipc-bwdxs WSL (Ubuntu, Python 3.10).

## Don't do

- Don't import `cv2` anywhere — it's not installed in the dispatch env.
- Don't ship the empty-directory placeholder as a fallback.
- Don't hardlink one EXR to fake the count.
- Don't synthesize depth from optical flow if the model fails. Abort.
- Don't include the model weights in the git repo (use Git LFS or
  download-at-build-time in CI, document the path clearly).
- Don't modify `bin/recorder_consumer_lite.py` — keep the wire-up as a
  separate spec (recorder integration comes after this lands).
