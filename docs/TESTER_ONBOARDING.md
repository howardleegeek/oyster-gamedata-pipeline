# Oyster GameData 内测用户指南

欢迎加入 Oyster GameData 内测计划！本指南将帮助你快速上手。

---

## 什么是 Oyster GameData？

Oyster GameData 是一款运行在 Windows 电脑上的小工具。它会在你玩游戏时自动记录游戏数据，并根据你的游戏时长和表现为你赚取收益。你只需要正常玩游戏，剩下的交给它——无需手动操作，无需额外设置。简单来说：**你玩游戏，它帮你赚钱**。

---

## 安装 Windows Installer

1. 从内测群下载 `OysterGameData-Setup.exe` 安装包
2. 双击运行安装程序
3. 如果 Windows 弹出安全提示，点击 **"更多信息" → "仍要运行"**
4. 按照安装向导点击 **"下一步"**，选择安装路径（默认即可）
5. 点击 **"安装"**，等待完成
6. 点击 **"完成"** 关闭安装向导

## 第一次启动 — OAuth 登录

1. 双击桌面 **Oyster GameData** 图标启动程序
2. 首次启动会自动打开浏览器，跳转到登录页面
3. 使用你的 **Google / GitHub / Microsoft** 账号登录（OAuth 授权）
4. 授权成功后，浏览器会提示 "登录成功，可以关闭此页面"
5. 回到桌面，Oyster GameData 主窗口会显示 **"已连接"** 状态

> 📸 `[截图位置：OAuth 授权页面]`

## 玩游戏赚 $ — 自动录制说明

- 启动 Oyster GameData 后，**自动录制** 功能默认开启
- 当你打开支持的游戏时，程序会自动开始记录游戏数据
- 录制内容包括：游戏时长、游戏内事件、性能数据
- **不会录制你的屏幕画面或麦克风声音**，仅记录结构化数据
- 录制数据会加密上传到服务器，用于计算你的收益
- 你可以在系统托盘（右下角）看到录制状态图标：
  - 🟢 绿色 = 正在录制
  - ⚪ 灰色 = 空闲（未检测到游戏）

---

## 查看收入通知 (Income Notification)

- 每次收益结算后，系统托盘会弹出通知
- 通知内容包含：本次收益金额、累计收益
- 你也可以在主窗口点击 **"收益"** 标签查看完整记录
- 收益每周结算一次，次周一发放

## 卸载方式

打开 Windows **设置 → 应用 → 安装的应用**，找到 **Oyster GameData**，点击 **"卸载"** 即可。
