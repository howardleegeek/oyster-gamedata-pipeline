## 🎯 Quality Standards / 质量标准

### Expected Deliverables / 预期交付物
1. **High-resolution screenshots** of each scene/variant
2. **Detailed scene descriptions** with specific dimensions and features
3. **Clear variant differentiation** showing distinct visual changes
4. **Logical route planning** with smooth camera movements
5. **Accurate support duration** estimates based on complexity

### 预期交付物
1. 每个场景/变种的**高分辨率截图**
2. 包含具体尺寸和特征的**详细场景描述**
3. 显示明显视觉变化的**清晰变种区分**
4. 具有平滑摄像机运动的**逻辑路线规划**
5. 基于复杂度的**准确支持时长**估算

### Technical Requirements / 技术要求
- **Resolution:** Minimum 1920x1080, preferred 4K
- **Frame rate:** 30fps minimum, 60fps preferred
- **Format:** MP4 with H.264 encoding
- **Duration:** 15-60 seconds per clip
- **File naming:** Consistent naming convention (e.g., SceneName_Variant_Route_001.mp4)

### 技术要求
- **分辨率:** 最低1920x1080，推荐4K
- **帧率:** 最低30fps，推荐60fps
- **格式:** MP4，H.264编码
- **时长:** 每个clip 15-60秒
- **文件命名:** 一致的命名约定（例如：SceneName_Variant_Route_001.mp4）

## 🔧 Template Customization / 模板自定义

### For Different Game Types / 针对不同游戏类型
- **FPS Games:** Emphasize first-person camera movements, weapon perspectives, and combat-ready positioning
- **RPG Games:** Focus on exploration paths, narrative viewpoints, and character-scale environments
- **Racing Games:** Highlight vehicle pathways, track layouts, and speed-appropriate camera angles
- **Simulation Games:** Showcase interactive elements, system demonstrations, and user interface integration

### 针对不同游戏类型
- **FPS游戏:** 强调第一人称摄像机移动、武器视角和战斗就位位置
- **RPG游戏:** 专注于探索路径、叙事视角和角色比例环境
- **竞速游戏:** 突出车辆路径、赛道布局和适合速度的摄像机角度
- **模拟游戏:** 展示交互元素、系统演示和用户界面集成

### Scene Complexity Guidelines / 场景复杂度指南
- **Low Complexity (60-80h):** Simple environments, limited interactivity, basic variants
- **Medium Complexity (80-100h):** Moderate detail, some interactivity, multiple variants
- **High Complexity (100-130h):** Highly detailed, extensive interactivity, comprehensive variants

### 场景复杂度指南
- **低复杂度 (60-80小时):** 简单环境、有限交互性、基本变种
- **中复杂度 (80-100小时):** 中等细节、一定交互性、多个变种
- **高复杂度 (100-130小时):** 高度详细、广泛交互性、全面变种
