# 录制 SOP（给老刘 / vendor）

## 装这些就够了

1. **Minecraft Java 版 1.20.4**（启动器里选 Fabric profile）
2. **Java 21**（启动器会自动装）
3. **Fabric API**（mod 文件夹丢一个 jar）
4. **Replay Mod 2.6.16**（mod 文件夹再丢一个 jar）

## MC 里这样设

- 窗口模式（不要全屏）
- 1920×1080
- FOV 70

## 录制怎么做

1. 双击桌面 `OysterRecorder` 图标
2. 打开 MC 进游戏
3. 切回 OysterRecorder 点 **▶ 开始录制**
4. 玩 5-6 分钟
5. 退出 MC，自动出 clip 到 `Documents\OysterClips\`

## 不要装

任何改 HUD / 加 logo / 加水印 / 加聊天弹窗的 mod。

完。
